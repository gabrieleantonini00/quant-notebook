# Quant Notebook

**Quantitative Methods & Statistical Learning**

A personal website for probability and statistics, econometrics, statistical learning, natural language processing, and quantitative finance. The 17 current study notes include worked examples, comparison tables, rendered equations, and calculated plots.

## Open locally

Open **index.html** in your browser. The subject index, topic search, article navigation, and mathematical typesetting work directly from the files. Fonts have system fallbacks when you are offline.

For editing with automatic reindexing, run this in PowerShell from this folder:

```powershell
.\Start-Notebook.ps1
```

Then open http://127.0.0.1:8000. Keep that terminal open; Ctrl+C stops the server. The launcher uses an installed Python or the Python bundled with Codex. If PowerShell blocks scripts, use `python serve.py`, or simply open `index.html` directly.

## Add or edit a note

1. Edit the corresponding HTML file in `notes/`.
2. For a new note, copy `notes/template_note.html` into a subject folder such as `notes/statistics/`. Change its title, description, heading, and topic order.
3. Use `h2` headings for the page’s table of contents. Use `$...$` for inline math and `$$...$$` for display math.
4. Run `python build_site.py`, or let `serve.py` rebuild automatically. Refresh your browser to see changes.

The builder fixes shared asset paths for each note’s folder depth, adds the reading layout, and indexes new notes. Add plots in `assets/plots/` with meaningful alt text and captions that explain their assumptions. Only notes actually present are listed as available.

- `templates/index.html`: homepage layout (edit this rather than generated `index.html`).
- `assets/site.css`: shared visual design, mobile layout, and print layout.
- `assets/library.js`: library filters, search, and note-card summaries.
- `assets/notes.js`: section navigation, reading progress, and print control.
- `assets/books.js`: reading-list data retained from the original website for future use.
- `content.json`, `index.html`, `all-notes.html`: generated by the builder.
- `scripts/check_site.py`: checks the note index, links, images, and headings.
- `assets/vendor/katex/`: pinned KaTeX 0.16.11 files and license, so math works offline.

If a renamed note has a custom short title or summary in `assets/library.js`, update that entry too. New notes automatically use their own metadata instead.

## GitHub repository and future updates

The public website is hosted with GitHub Pages at [gabrieleantonini00.github.io/quant-notebook](https://gabrieleantonini00.github.io/quant-notebook/). The publishing source is the root folder of the `main` branch. GitHub Pages republishes the site after each push to `main`; changes kept locally do not affect the published website. The `.nojekyll` file lets GitHub serve the generated HTML and assets directly.

Keep the local checkout for editing, rebuilding, and checking notes. The published website is served by GitHub and remains available when your computer is off. All site links are relative so they work under the repository's `/quant-notebook/` URL.

After editing or adding notes, run:

```powershell
python build_site.py
python scripts/check_site.py --strict-assets
git add -A
git commit -m "Update learning notebook"
git push
```

The `.gitignore` keeps local backups, previews, logs, credentials, Python caches, and the two original research PDFs out of Git. The reviewed material appears in the HTML notes; the source PDFs remain local.

Official references: [Creating a repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository), [GitHub Pages visibility](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Content and validation

Numerical examples use explicitly stated illustrative inputs. The risk notes distinguish confidence levels from tail probabilities and loss values from signed-return quantiles. Original root files are retained in `.local-backup/` as a local snapshot.

Run `python build_site.py` followed by `python scripts/check_site.py` after editing. This is a static website: Python is needed to rebuild the index and run the optional local server, but visitors only need a browser.
