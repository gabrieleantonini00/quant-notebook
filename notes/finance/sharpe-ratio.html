Sharpe & Sortino Ratios

Risk-adjusted performance metrics: quantifying excess return per unit of total volatility versus downside risk.

Total Volatility Risk

Sharpe Ratio

Measures excess portfolio return per unit of total standard deviation ($\sigma_p$), treating upside and downside deviations symmetrically.

Downside Risk Only

Sortino Ratio

Measures excess return over a benchmark target per unit of downside deviation ($\sigma_d$), penalizing only harmful losses.

The Sharpe Ratio

The Sharpe Ratio evaluates the risk-adjusted return of an investment portfolio by comparing its expected excess return over the risk-free rate to its overall volatility:

$$\text{Sharpe Ratio} = \frac{\mathbb{E}[R_p - R_f]}{\sigma_p}$$

where:

  • $R_p$: Portfolio return.
  • $R_f$: Risk-free benchmark rate (e.g. Treasury bill yield).
  • $\sigma_p = \sqrt{\text{Var}(R_p)}$: Portfolio-return standard deviation when the benchmark is constant. With a varying benchmark, use $\operatorname{sd}(R_p-R_f)$ in the denominator.
Limitation of the Sharpe Ratio

Standard deviation penalizes both harmful losses and beneficial large positive returns equally. For investment strategies with asymmetric or positively skewed return profiles (such as trend following or long-option strategies), large upside moves can increase the denominator too. Whether that is a useful risk summary depends on the question; Sharpe does not describe tail losses or the full return distribution.

The Sortino Ratio

The Sortino Ratio modifies the Sharpe Ratio by replacing total standard deviation with Downside Deviation (Semi-Standard Deviation), measuring excess return relative to a Minimum Acceptable Return ($\text{MAR}$ or $\tau$):

$$\text{Sortino Ratio} = \frac{\mathbb{E}[R_p - \tau]}{\sigma_d}$$

Downside Deviation ($\sigma_d$)

Downside deviation isolates only returns that fall below the target threshold $\tau$:

$$\sigma_d = \sqrt{\frac{1}{T} \sum_{t=1}^T \min(0,\, R_{p,t} - \tau)^2}$$

Any return $R_{p,t} \ge \tau$ yields a deviation of zero, ensuring that upside volatility never penalizes the strategy score.

Takeaway: the higher Sortino value reflects a different denominator. It does not mean the portfolio performed better when measured a second time.

Reading a reported ratio carefully

State the observation period, return frequency, benchmark, fees, and denominator convention. Keep returns and benchmark rates at the same frequency. Neither ratio is finite when its denominator is zero, and a short history can make either estimate unstable.

For approximately additive excess returns with stable moments and no serial correlation, the common annualization is $S_{\mathrm{annual}}\approx\sqrt{m}\,S_{\mathrm{period}}$, where $m$ is the number of periods per year. Compounding and serial correlation can invalidate this shortcut.
