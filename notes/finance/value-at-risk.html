Value at Risk

Definition

Let $r_{t+1}$ be the future return of a portfolio or asset at time $t + 1$. The Value-at-Risk ($\text{VaR}$) at coverage / confidence level $\alpha \in (0, 1)$ (commonly $95\%$ or $99\%$) is written here as a signed return threshold. Under a continuous return distribution, returns fall below it with probability $1 - \alpha$:

$$\mathbb{P}(r_{t+1} < \text{VaR}_\alpha) = 1 - \alpha$$

A negative threshold denotes a loss. For portfolio value $V$ and simple returns, the corresponding cash-loss VaR is $-V\,\text{VaR}_\alpha$. Keep the horizon fixed when comparing estimates. Assuming $F$ is the continuous cumulative distribution function (CDF) of $r_{t+1}$, $\text{VaR}_\alpha$ corresponds mathematically to the $(1 - \alpha)$-th lower quantile of the return distribution:

$$\text{VaR}_\alpha = F^{-1}(1 - \alpha)$$

Parametric Models

Write $r_t = \mu_t + \epsilon_t$, where $\mu_t$ is the conditional mean and $\epsilon_t$ is the innovation. Given the information $\mathcal F_{t-1}$ available before time $t$:

$$\mathbb E[\epsilon_t\mid\mathcal F_{t-1}]=0,\qquad \operatorname{Var}(\epsilon_t\mid\mathcal F_{t-1})=\sigma_t^2$$

The conditional VaR follows by adding $\mu_t$ to the innovation's conditional $(1-\alpha)$-quantile:

$$\text{VaR}_{\alpha,t} = \mu_t + Q_{1-\alpha}(\epsilon_t\mid\mathcal F_{t-1})$$

Location-Scale Distributions

  • Gaussian (Normal): If $\epsilon_t\mid\mathcal F_{t-1}\sim\mathcal N(0,\sigma_t^2)$: $$\text{VaR}_{\alpha,t} = \mu_t + \sigma_t \Phi^{-1}(1 - \alpha)$$
  • Student's $t$: For a Student's $t$ innovation with $\nu > 2$ degrees of freedom, scaled to conditional variance $\sigma_t^2$: $$\text{VaR}_{\alpha,t} = \mu_t + \sigma_t \sqrt{\frac{\nu - 2}{\nu}} \, t^{-1}_{1-\alpha, \nu}$$

Conditional Volatility Specifications ($\sigma_t^2$)

The recursions below assume zero conditional mean; otherwise replace squared returns with squared innovations $r_{t-1}-\mu_{t-1}$.

  1. EWMA (Exponentially Weighted Moving Average): Assigns exponentially decaying weights to past returns using decay factor $\lambda$ (typically $\lambda = 0.94$ for daily returns): $$\sigma_t^2 = (1 - \lambda) r_{t-1}^2 + \lambda \sigma_{t-1}^2$$
  2. GARCH(1,1): Incorporates mean-reverting volatility with long-run unconditional variance $\omega / (1 - \alpha_1 - \beta_1)$ when $\omega>0$, $\alpha_1,\beta_1\ge0$, and $\alpha_1+\beta_1<1$: $$\sigma_t^2 = \omega + \alpha_1 r_{t-1}^2 + \beta_1 \sigma_{t-1}^2$$

Nonparametric Models

Standard Historical Simulation (HS)

Historical Simulation avoids parametric assumptions by estimating VaR directly from the empirical quantile of the last $N$ rolling return observations:

$$\text{VaR}_t(\alpha) = \text{Quantile}_{1-\alpha}\{r_s\}_{s=t-N}^{t-1}$$

Volatility-Weighted Historical Simulation (VWHS)

Updates historical returns to reflect current market volatility conditions, scaling historical return shocks by the ratio of current to past conditional volatility (the expression below uses zero-mean returns):

$$r_s^* = r_s \left( \frac{\sigma_t}{\sigma_s} \right)$$

Semiparametric Models

CAViaR

Instead of modeling the full conditional density or variance, CAViaR (Conditional Autoregressive Value at Risk) models the evolution of the quantile $f_t(\boldsymbol{\beta})$ directly through an autoregressive time-series process. Under the Asymmetric Slope specification:

$$f_t(\boldsymbol{\beta}) = \beta_1 + \beta_2 f_{t-1}(\boldsymbol{\beta}) + \beta_3 \max(r_{t-1}, 0) + \beta_4 \min(r_{t-1}, 0)$$

The parameters $\boldsymbol{\beta}$ are estimated via non-linear regression using the asymmetric Pinball (Check) Loss function:

$$\min_{\boldsymbol{\beta}} \sum_{t=1}^T \rho_{p_0}\left(r_t - f_t(\boldsymbol{\beta})\right) \quad \text{where} \quad p_0=1-\alpha,\quad \rho_{p_0}(u) = u\left(p_0 - \mathbb{I}_{u < 0}\right)$$

Hybrid Models

A hybrid approach can combine several volatility forecasts into a positive estimate $\widehat{\sigma}_t$. Filtered historical simulation then maps past standardized shocks to today's scale:

$$z_s=\frac{r_s-\widehat{\mu}_s}{\widehat{\sigma}_s},\qquad r_s^*=\widehat{\mu}_t+\widehat{\sigma}_t z_s,\qquad \widehat{\text{VaR}}_{\alpha,t}=\text{Quantile}_{1-\alpha}\{r_s^*\}$$

Alternatively, a neural network can forecast the quantile directly using the pinball loss above. These are modeling choices, not guarantees of better forecasts. A recurrent model must receive only information available at the forecast time; even a bidirectional network must be restricted to a fully historical input window.

Backtesting

A risk model must never be validated solely on in-sample training data. Out-of-sample backtesting evaluates the predictive accuracy of the model on a sequence of unseen holdout observations using rolling or expanding estimation windows:

Rolling forecast cycle

  1. 01Estimation window$t-T,\ldots,t$
  2. 02Fit & forecast$\widehat{\mathrm{VaR}}_{\alpha,t+1\mid t}$
  3. 03Observe return$r_{t+1}$
  4. 04Record exception$\mathrm{Hit}_{t+1}$

For each out-of-sample evaluation step $t+1$, the binary Hit exception indicator is recorded:

$$\text{Hit}_{t+1} = \mathbb{I}\left(r_{t+1} < \widehat{\text{VaR}}_{\alpha, t+1 \mid t}\right) = \begin{cases} 1 & \text{if loss exceeds VaR (Exception)} \\ 0 & \text{if return within VaR limit} \end{cases}$$

Unconditional Coverage Test (Kupiec's POF Test)

Verifies whether the empirical out-of-sample violation rate $\hat{p} = x/N$ is statistically indistinguishable from the expected tail probability $p_0=1-\alpha$ across $N$ test days ($x = \sum_{t=1}^N \text{Hit}_t$):

$$LR_{\text{uc}} = -2 \ln \left[ \frac{(1 - p_0)^{N-x} p_0^x}{(1 - \hat{p})^{N-x} \hat{p}^x} \right] \sim \chi^2(1)$$

Independence & Conditional Coverage Tests (Christoffersen Framework)

Evaluates whether exceptions occur independently over time without dangerous volatility clustering:

  • Independence Test ($LR_{\text{ind}}$): Tests first-order dependence between consecutive exceptions using a Markov transition matrix: $$LR_{\text{ind}} = -2 \ln \left[ \frac{(1 - \hat{\pi})^{N_{00}+N_{10}} \hat{\pi}^{N_{01}+N_{11}}}{(1 - \hat{\pi}_{01})^{N_{00}} \hat{\pi}_{01}^{N_{01}} (1 - \hat{\pi}_{11})^{N_{10}} \hat{\pi}_{11}^{N_{11}}} \right] \sim \chi^2(1)$$
  • Conditional Coverage Test ($LR_{\text{cc}}$): Joint test checking both correct exception count and serial independence:
    $$LR_{\text{cc}} = LR_{\text{uc}} + LR_{\text{ind}} \sim \chi^2(2)$$

Dynamic Quantile (DQ) Test

Defines the de-meaned hit variable $\text{Hit}_t^* = \text{Hit}_t - p_0$. Under the null hypothesis $H_0$ of correct model specification, $\text{Hit}_t^*$ must be orthogonal to past hits and lagged VaR forecasts:

$$\text{Hit}_t^* = \delta_0 + \sum_{i=1}^p \delta_i \text{Hit}_{t-i}^* + \delta_{p+1} \widehat{\text{VaR}}_t + \epsilon_t$$

With a full-rank design and standard regularity assumptions, the DQ statistic $DQ = \frac{\hat{\boldsymbol{\delta}}' X' X \hat{\boldsymbol{\delta}}}{p_0(1 - p_0)} \sim \chi^2(p + 2)$ tests whether these predictors explain the centered hits. The chi-squared reference distributions in this section are asymptotic approximations; passing a test is not proof that a risk model is correct.
