Embeddings & Word2Vec

Word Embeddings

Unlike traditional discrete Bag-of-Words where words are orthogonal and word order is neglected, Word2Vec constructs dense, continuous numeric vectors in a lower-dimensional space $\mathbb{R}^d$ (typically $d \in [100, 300]$).

Words that occur in similar linguistic contexts are mapped to nearby geometric locations, operationalizing the distributional hypothesis: "You shall know a word by the company it keeps."

Continuous Bag of Words (CBOW)

In the Continuous Bag of Words (CBOW) formulation, the objective is to predict a missing target center word $w_t$ given a window of $C$ surrounding context words $\{w_{t-c}, \dots, w_{t+c}\} \setminus \{w_t\}$.

Projection and Prediction

Input Layer ($X$)
One-hot encoded vectors of the $C$ context words:
$$\mathbf{x}_i \in \mathbb{R}^{1 \times D} \quad (D = \text{vocabulary size})$$
Hidden Layer ($h$)
A linear bottleneck projection (typically 100–300 nodes) computing the average of input vectors multiplied by the input weight matrix $W \in \mathbb{R}^{D \times d}$:
$$h = \frac{1}{C} \sum_{i=1}^C \mathbf{x}_i \cdot W$$
Note: The hidden layer uses no non-linear activation function.
Output Layer ($u$)
Projected from the hidden state using a separately learned output weight matrix $W' \in \mathbb{R}^{d \times D}$ (it is not constrained to equal $W^T$):
$$u = h \cdot W'$$
Softmax Prediction
The conditional probability of a target word $w_c$ given its context is computed using normalized exponentials:
$$P(w_c \mid \text{context}) = \frac{\exp(u_c)}{\sum_{j=1}^D \exp(u_j)}$$

CBOW and Skip-Gram

Word2Vec provides two complementary training formulations:

  • CBOW (Continuous Bag of Words): Predicts target word $w_t$ given context words. Averaging makes the representation insensitive to order within that context window.
  • Skip-Gram: Predicts surrounding context words given a single input target word $w_t$. It creates multiple prediction pairs from each window; performance depends on the corpus and training settings.

The full softmax above explains the prediction objective. Practical training often uses hierarchical softmax or negative sampling to avoid scoring the whole vocabulary for every example.

Vector Geometry

The resulting learned weight matrix $W$ contains dense word vectors in its rows. Some learned relations can be expressed approximately as vector offsets:

$$\mathbf{v}_{\mathrm{King}}-\mathbf{v}_{\mathrm{Man}}+\mathbf{v}_{\mathrm{Woman}}\approx\mathbf{v}_{\mathrm{Queen}}$$

Semantic similarity is measured using the cosine of the angle between vectors:

$$\text{CosineSimilarity}(\mathbf{u}, \mathbf{v}) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2}$$

The king–man+woman analogy is an intuition for relationships learned from a corpus. The dimensions are not labeled “royalty” or “gender”, and the nearest word is not guaranteed to be “queen”.

Static and Contextual Embeddings

Word2Vec assigns one fixed vector to each vocabulary item regardless of its surrounding sentence. For example, "bank" has the same vector in “river bank” and “bank account”. If preprocessing lowercases text, “apple” and “Apple” also become the same item; a case-sensitive vocabulary can keep them separate. Contextual models such as BERT instead compute a representation for each occurrence using its context.
