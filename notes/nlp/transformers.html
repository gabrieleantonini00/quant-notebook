Transformers & BERT

Transformer Architecture

The Transformer architecture (Vaswani et al., 2017 ↗) replaces recurrence and convolutions with attention and position-wise feed-forward layers. Token positions can be processed in parallel during training. Self-attention connects any two positions within one layer, but this constant path length is not constant computational cost: dense attention over $L$ tokens costs $\mathcal{O}(L^2d)$ for hidden dimension $d$.

Input & Positional Encoding

Given an input sequence of tokens of length $L$, the continuous embedding matrix $X \in \mathbb{R}^{L \times d_{\text{model}}}$ (originally $d_{\text{model}} = 512$) is constructed as:

$$X = E_{\text{token}} \cdot \sqrt{d_{\text{model}}} + PE$$

where $E_{\text{token}}$ is randomly initialized or pre-computed, and $PE$ denotes the sinusoidal Positional Encoding:

$$PE_{(pos,\, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right)$$
$$PE_{(pos,\, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right)$$

Encoder Blocks

In the original base model, $N=6$ Encoder blocks refine contextual representations. The dimensions and layer counts below describe that model, not every Transformer:

Multi-Head Self-Attention

The input $X$ is projected into Queries ($Q$), Keys ($K$), and Values ($V$) using independent weight matrices for each head ($h = 8$ heads):

$$Q_i = X W_i^Q, \quad K_i = X W_i^K, \quad V_i = X W_i^V \quad \text{for } i \in \{1, \dots, h\}$$

Scaled Dot-Product Attention

$$\text{head}_i = \text{softmax}\left(\frac{Q_i K_i^T}{\sqrt{d_k}}\right) V_i$$

where $d_k = d_{\text{model}} / h = 64$. The heads are concatenated and projected via $W^O$:

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O$$

Residual Add & LayerNorm

$$X_{\text{norm1}} = \text{LayerNorm}(X + \text{MultiHeadAttention}(X))$$

Position-Wise Feed-Forward Network (FFN)

$$\text{FFN}(x) = \max(0,\, x W_1 + b_1) W_2 + b_2$$

Final Add & Norm Output

$$X_{\text{out}} = \text{LayerNorm}(X_{\text{norm1}} + \text{FFN}(X_{\text{norm1}}))$$

Decoder Blocks

The Decoder processes target sequences shifted right ($Y = E_{\text{target}}\sqrt{d_{\text{model}}} + PE$ in the original model) and generates autoregressive outputs:

  • Masked Multi-Head Attention: Applies an upper-triangular mask matrix $M$ (with $0$ and $-\infty$) to prevent positions from attending to future tokens before Softmax.
  • Cross-Attention: Queries are computed from the Decoder, while Keys and Values are extracted from the final Encoder output:
    $$Q_{\text{cross}} = Y_{\text{masked}} W^Q, \quad K_{\text{cross}} = X_{\text{enc\_final}} W^K, \quad V_{\text{cross}} = X_{\text{enc\_final}} W^V$$
  • Model Head (Linear Projection & Softmax): Converts decoder hidden representations into token probabilities across the full vocabulary:
    $$Z = Y_{\text{out}} W_{\text{out}} + b_{\text{out}} \quad (\text{Linear Projection})$$
    $$P_i = \frac{\exp(Z_i)}{\sum_j \exp(Z_j)} \quad (\text{Softmax})$$

BERT

BERT (Bidirectional Encoder Representations from Transformers) (Devlin et al., 2018 ↗) leverages solely the Encoder stack of the Transformer architecture to learn deep bidirectional representations of text.

Input Representation

Input sequences are structured as: [CLS] text A [SEP] text B [SEP].

The final input embedding $X$ is constructed as the element-wise sum of three embeddings:

$$X = E_{\text{input}} = E_{\text{token}} + E_{\text{pos}} + E_{\text{seg}}$$
  • $E_{\text{token}}$: WordPiece token embeddings.
  • $E_{\text{pos}}$: Learned positional embeddings.
  • $E_{\text{seg}}$: Segment identifiers (distinguishing sentence A from sentence B).

Pre-Training Objectives

  1. Masked Language Modeling (MLM): $15\%$ of token positions are selected for prediction. Of those selected positions, $80\%$ receive [MASK], $10\%$ receive a random token, and $10\%$ stay unchanged. The loss predicts the original token at every selected position.
  2. Next Sentence Prediction (NSP): A classifier using the [CLS] representation predicts whether B is the actual next sentence after A in the corpus or a randomly sampled sentence. This is not a test of logical entailment.
