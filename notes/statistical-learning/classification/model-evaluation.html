Model Evaluation

Decision Thresholds

For a binary target $y\in\{0,1\}$ and estimated positive-class probability $\hat p(x)$, the threshold $\theta$ defines the decision:

$$\hat y(x)=\begin{cases}1 & \hat p(x)\ge\theta,\\0 & \hat p(x)<\theta.\end{cases}$$

Evaluation depends on the positive class, class prevalence and decision rule. Select the threshold on validation data using the relevant error costs or capacity constraints, then freeze it for test evaluation. Fit preprocessing within the training data; use splits appropriate to temporal or grouped observations.

Precision conditions on predicted positives; recall conditions on actual positives. Their denominators therefore refer to different populations.

Accuracy & Class Imbalance

$$\operatorname{Accuracy}=\frac{TP+TN}{TP+TN+FP+FN}.$$

Accuracy measures the overall fraction of correct decisions. If positive-class prevalence is $\pi$, always predicting negative achieves accuracy $1-\pi$ while detecting no positives. Report class supports and class-specific performance when frequencies are uneven.

Precision & Recall

Precision

$$\operatorname{Precision}=\frac{TP}{TP+FP}.$$

The fraction of predicted positives that are correct, also called positive predictive value.

Recall

$$\operatorname{Recall}=\frac{TP}{TP+FN}.$$

The fraction of actual positives detected, also called sensitivity or true positive rate.

On a fixed dataset, raising the threshold reduces or leaves unchanged the number predicted positive, so recall cannot increase. Lowering it cannot decrease recall. Precision can move in either direction.

Precision is undefined if no observations are predicted positive; recall is undefined if no actual positives are present. State the convention used for zero denominators.

F-Scores

$F_1$ combines precision $P$ and recall $R$ through their harmonic mean:

$$F_1=\frac{2PR}{P+R}=\frac{2TP}{2TP+FP+FN}.$$

It rewards jointly high precision and recall and ignores true negatives. The general score changes their relative emphasis:

$$F_\beta=\frac{(1+\beta^2)PR}{\beta^2P+R},\qquad\beta>0.$$
$$F_\beta=\frac{(1+\beta^2)TP}{(1+\beta^2)TP+\beta^2FN+FP}.$$
  • $\beta<1$: greater emphasis on precision.
  • $\beta=1$: equal emphasis.
  • $\beta>1$: greater emphasis on recall.

Maximising an F-score is not generally equivalent to minimising a specified error cost or meeting a review-capacity constraint. The count form of $F_1$ is defined when its denominator is positive; when all three counts are zero, specify a reporting convention.

Multiclass Averaging

For $K>2$ classes, compute each class's counts against all remaining classes, then choose an aggregation rule:

Averaging Mode Mathematical Formulation Properties & Best Use Case
Macro Average $$\frac{1}{K} \sum_{k=1}^K \text{Score}_k$$ Unweighted arithmetic mean across all classes. Gives equal weight to rare and frequent classes.
Weighted Average $$\sum_{k=1}^K \frac{N_k}{N} \text{Score}_k$$ Weights each class score by its true support $N_k$. Frequent classes dominate; minority-class failure can be hidden.
Micro Average $$\text{Calculated globally from } \sum \text{TP}_k, \sum \text{FP}_k, \sum \text{FN}_k$$ Pools counts. Micro precision, recall, and F1 equal accuracy for single-label multiclass prediction when all classes are included; this does not generally hold for multilabel tasks.

Macro F1 averages class-wise F1 scores, rather than applying the F1 formula to macro precision and macro recall. Report class supports $N_k$ and uncertainty alongside aggregate scores, especially when some classes are rare.
