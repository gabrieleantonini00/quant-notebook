Supervised Learning

Explainable AI (XAI)

Explanation Scope

Let $f(x)$ be the scalar output being explained, such as a class score, probability or log-odds. Local methods describe one prediction; global methods summarise behaviour over a reference population. An intrinsically interpretable model exposes its fitted structure, while post-hoc methods analyse an already trained model.

Explanations depend on the output scale and reference distribution. They describe model behaviour; causal effects, predictive performance and fairness require their own evidence.

Local Surrogate Models (LIME)

LIME approximates $f$ near the observation $x$ with an interpretable surrogate $g$. It balances local fit against model complexity:

$$g_x^*\in\arg\min_{g\in\mathcal G}\left\{L(f,g,\pi_x)+\Omega(g)\right\}.$$

Here $\pi_x$ weights perturbed observations by proximity to $x$, $L$ measures weighted disagreement with the original model, and $\Omega$ penalises complexity. The surrogate can use an interpretable representation of the inputs.

Coefficients describe the chosen neighbourhood. Their reliability depends on local fidelity, perturbation realism, kernel width and stability across repeated fits.

Additive Feature Attributions (SHAP)

SHAP allocates the difference between a reference output and $f(x)$ across the features. For a specified coalition value function $v_x(S)$, the Shapley attribution is:

$v_x(S)$ averages the model output with features in $S$ fixed to their values in $x$, using the chosen rule for the remaining features.

$$\phi_j=\sum_{S\subseteq P\setminus\{j\}}\frac{|S|!(p-|S|-1)!}{p!}\left[v_x(S\cup\{j\})-v_x(S)\right],$$

where $P=\{1,\ldots,p\}$. Each contribution averages the feature's incremental value over coalitions, with weights equivalent to averaging over feature orderings. When $v_x(P)=f(x)$, local accuracy gives:

$$f(x)=\phi_0+\sum_{j=1}^{p}\phi_j,\qquad \phi_0=v_x(\varnothing).$$

The definition of a missing feature matters. Conditional expectations preserve feature dependence; marginal background substitutions answer a different question and can create unsupported combinations. Attributions inherit those choices and the chosen output scale. Log-odds contributions add before applying the sigmoid.

Path Attributions (Integrated Gradients)

For a differentiable $f$ and baseline $x'$, integrated gradients accumulate input derivatives along the straight path from $x'$ to $x$:

$$\operatorname{IG}_j(x;x')=(x_j-x'_j)\int_0^1\frac{\partial f(x'+\alpha(x-x'))}{\partial x_j}\,d\alpha.$$

Under the regularity conditions for integrating the gradient along this path, completeness gives:

$$\sum_j\operatorname{IG}_j(x;x')=f(x)-f(x').$$

The baseline determines the reference question. A finite numerical approximation can leave a completeness residual; intermediate inputs on the path may also lie outside the data distribution.

Counterfactual Explanations

A counterfactual searches for a nearby feasible input that achieves a target model decision. For a binary probability output:

$$x^*\in\arg\min_{x'\in\mathcal F}d(x,x')\quad\text{subject to}\quad\hat p(x')\ge\theta.$$

The feasible set $\mathcal F$ encodes immutable features and admissible combinations. The distance $d$ can reflect the number, size or cost of changes. Several distinct solutions may exist, or none may be feasible. Crossing the model's boundary does not by itself establish the real-world effect of an intervention.

Partial Dependence & ICE

For feature $j$, replace its value by $z$ while keeping each observation's remaining features $x_{i,-j}$. ICE retains the individual prediction curves; PDP averages them:

$$\operatorname{ICE}_i(z)=f(z,x_{i,-j}),$$
$$\operatorname{PDP}_j(z)=\frac{1}{n}\sum_{i=1}^{n}\operatorname{ICE}_i(z).$$

PDP averages over the empirical marginal distribution of the remaining features. It is generally different from $E[f(X)\mid X_j=z]$. ICE reveals heterogeneous responses that their average can hide.

When inputs are dependent, the sweep can evaluate combinations absent from the data. Centre ICE curves at a common reference value to compare changes rather than differences in baseline levels.

Accumulated Local Effects (ALE)

ALE averages local prediction changes within the observed feature distribution, then accumulates and centres them. For a continuous feature and differentiable model, a first-order effect can be written as:

$$g_j(z)=\int_{z_0}^{z}E\!\left[\frac{\partial f(u,X_{-j})}{\partial u}\,\middle|\,X_j=u\right]du,$$
$$\operatorname{ALE}_j(z)=g_j(z)-E[g_j(X_j)].$$

In practice, divide the feature into intervals and average finite prediction differences between each interval's endpoints, using observations belonging to that interval. Accumulate those differences and centre with respect to the observed feature distribution.

ALE reduces the long-range extrapolation of a PDP sweep. Interval width, sparse regions and dependence still affect the estimate. Its centred level is a model-output effect, not the model's prediction for an individual.

Explanation Quality & Robustness

Fidelity measures agreement with the original model over the domain an explanation claims to describe. Stability concerns sensitivity to sampling, background data, baselines and reasonable method settings. A stable explanation can still be unfaithful, and a faithful local explanation need not describe the model globally.

An adversarial perturbation changes an input to induce a model error under a specified constraint. This probes predictive robustness; the attack itself is not a feature attribution or a feasible recourse plan.
